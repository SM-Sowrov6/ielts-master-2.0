# Prompt templates

Layout: `<feature>/<name>@<semver>.md`, e.g. `writing/criterion_lr@1.0.0.md` → key `writing.criterion_lr`.

Rules (docs/AI_ENGINE_ARCHITECTURE.md §8):
- Every change to a prompt is a **new version file**. Never edit a released version in place.
- Prompt changes require the AI evaluation gate before merge (Phase 8+).
- No prompts exist yet. They are added with the first workflow in Phase 8/9.
